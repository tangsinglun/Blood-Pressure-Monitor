## OverView

This project is a Nutrient Calculator written in excel. Not like other nutrient app, it allows you to acculately calculate your meal's nutrient base on the portion you consume.

## Installation

As said this nutrient calculator is written in excel. In order to use it, you must need to install window office with excel installed. This app used macros, therefore you need to have
macros installed or enabled in the excel. This nutrient calculator is developed on Micorsoft excel but also have tested on LibreOffice. LibreOffice compared to microsoft office is a free version. 

* Enable Macros on LibreOffice
    1. Go to Tools on the menu item
    2. Select Options
    3. Select Security
    4. Click on Macro Security on the left pane.
    5. For the Security Level tap, select "Medium" or "Low" for the option. 

## Config-Ussage

* For the app configuration. There are prdefined templates.

    1. Ingredient Template
        -  Don't corrupte this template. If you want to use it, add a new worksheet. For instance if you want to use it as breakfast, add a new worksheet, rename it to "Breakfast demo". And then copy the whole worksheet from the ingredient template to the new "Breakfast demo" worksheet. To copy the whole worksheet. you can click "ctl a" and "ctl c" to copy it. Then on the "Breakfast" worksheet, click "ctl v" to paste it. 
        - Fill in the nutrient data for the "breakfast", check on the breakfast demo.
    2. Menu Nutrient Record Template
        -  Don't corrupte this template. If you want to use it, select the relevant worksheet. For instance if you are working on "January", select "January Meal Record". on the cell "M3", please rename the worksheet for the first item from "Ingredient Template" to "Breakfast demo", the name should be the same as your ingredient worksheet you just newly added.  Then copy the part of the template from the cell "A1" to "K31" not the whole page from the "Menu Nutrient Record Template" (click "clt c" to copy it) to the "January Meal Record". To paste it, select the cell "A2" and then click "clt v" to paste it. 
    3. Ussage
        - After the above procedure, you just need to fill in the correct dates. Whenever you want to record a particular date, just follow the point 2 procedure and type in the correct date. If you have any meal change or added, just rename the worksheet accodingly. 
        - When finish adding the new record for a particular meal, don't forget to click on the "Complete" button to confirm. Please take attention, when the "complete" button is clicked, all the data will be locked and setted. Any changes to the ingredients for the menu will not be updated to the menu nutrient record.
